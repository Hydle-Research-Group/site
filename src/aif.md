### Definitions

- By **"AI", "Generative AI", "AI-generated", or Artificial-Intelligence**, we define it as "any text, images, audio, or video generated entirely by digital systems and/or neural networks." This includes the prompting device written by humans, regardless if the human interfered or not during the generative process.

- By **"element of creation"**, we define it as "anything that is created or made."

- By **"real people"**, we define it as "any individual human being with consciousness."

- By **"asset(s)"**, we define it as "any binary data and/or individual files that an element of creation may rely upon to function."

### Requirements

In order to certify a project, organization, or any element of creation with the AIF, the following requirements must be met:

> **No. 1**  
> The element of creation made no use of AI during its construction and/or conceptualization.

> **No. 2**  
> The element of creation isn't actively using AI during new logic implementations and/or updates.

> **No. 3**  
> The element of creation doesn't use AI on any subsidiaries and/or additional elements of creation.

> **No. 4**  
> The element of creation doesn't contain AI-generated assets, such as images, audio, video.

### Exceptions

The AIF allows strict exceptions in which the use of AI doesn't violate it:

> **No. 1**  
> The element of creation includes language translations created by AI. If the text was originally constructed by real humans (Requirements No. 1), then translated to another language using AI, the AIF can still be applied to the element of creation.

> **No. 2**  
> The element of creation includes the implementation of AI. If still constructed by real humans (Requirements No. 1), and maintained by real humans (Requirements No. 2), then the implementation of an AI is allowed to use the AIF.

### How To Use

To apply the AIF to an element of creation, you can download the SVG logo [here](https://github.com/Hydle-Research-Group/media/blob/main/logos/aif.svg). The logo can be used anywhere in an element of creation, **as long as** all requirements described above are met.

*Modifying the logo is not allowed and heavily discouraged. Any modification will result in an invalid AIF element of creation.*
